# drones

One record per drone: `drone-<ID>.md` (copy [`TEMPLATE.md`](TEMPLATE.md)) and a folder
`drone-<ID>/` with its PX4 parameter snapshots (before setup, after calibration, ...).

Why: drones differ (wiring, battery, ports), and when something breaks later we need to know
what each drone was set to and what was already checked.

**IDs in use** (each drone sharing a router needs its own; it decides its IP):

| ID | Record | Status |
